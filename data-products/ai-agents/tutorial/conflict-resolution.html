Multi-Agent Coordination

Resolve agent conflicts with explicit protocols

Multiple agents can disagree about plans, evidence, ownership, or resource use. A production system needs deterministic escalation rules instead of asking agents to negotiate indefinitely.

Answer in brief

Define resource ownership, priority and evidence rules, use transactional shared state, limit negotiation rounds, and send unresolved or high-risk conflicts to a separate policy service or human approver.

Conflict types

Use these dimensions to make the architecture decision explicit and testable.

Plan conflict

Agents propose incompatible actions for the same goal.

State conflict

Concurrent workers read and write different versions of shared state.

Resource conflict

Workers compete for budgets, locks, tools, or human attention.

Policy conflict

A locally useful action violates a global rule or approval boundary.

Resolution hierarchy

Use these dimensions to make the architecture decision explicit and testable.

Prevent

Partition responsibilities and validate ownership before execution.

Detect

Use version checks, invariants, and conflict events.

Arbitrate

Apply policy, evidence quality, risk, and priority rules outside the agents.

Escalate

Route ambiguous or consequential disputes to a human with a concise evidence packet.

Evidence and audit

Use these dimensions to make the architecture decision explicit and testable.

Claims

Require every proposal to state assumptions and evidence references.

Decision record

Store the alternatives, rule applied, winner, and rejected actions.

Timeouts

Bound negotiation and choose a safe default when no agreement is reached.

Evaluation

Measure conflict rate, resolution latency, reversals, and harmful outcomes.

Production checklist

Use this as a design-review gate before release.

  1. Assign ownership for every mutable resource.
  2. Use optimistic locking or transactions.
  3. Keep arbitration outside individual agents.
  4. Cap negotiation rounds.
  5. Define safe defaults and escalation.
  6. Record the evidence and rule behind every resolution.
