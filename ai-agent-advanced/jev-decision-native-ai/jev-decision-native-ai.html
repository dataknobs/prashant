Three core primitives form a decision vocabulary

Read slide 9 text
PRIMITIVES Three core primitives form a decision vocabulary Choose the question type based on the answer space—not the wording of the prompt. DATAKNOBS / DECISIONNATIVE AI 09 NOMINAL CHOICE Pick one label from a defined set. Outputs: selected choice, distribution across options, confidence. Examples: department, next agent, complaint category. ORDINAL SCORE Place a record on an ordered rubric. Outputs: weighted score, level distribution, confidence. Examples: severity, relevancy, response quality. BINARY NOUL Evaluate one true/false proposition. Outputs: yes probability from 0 to 1; no separate confidence value. Examples: human requested, contains PII. You can ask all three types about the same input in ONE API request.
