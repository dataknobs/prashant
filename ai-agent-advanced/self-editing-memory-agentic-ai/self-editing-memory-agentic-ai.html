ORCHESTRATION A safe read–reason–propose–commit loop Pseudocode: model intent is advisory; deterministic checks control persistence. DATAKNOBS / GOVERNED AGENT MEMORY 28 PYTHONLIKE PSEUDOCODE async def respond(query, actor): context = await compile_context( query, actor=actor, scope=actor.scope) answer, proposals = await agent.run( query=query, context=context) for p in proposals: decision = await policy.evaluate(p, actor) if decision == "AUTO_COMMIT": await store.commit_if_version(p) elif decision == "REVIEW": await review_queue.enqueue(p) return answer BOUNDARIES Read permissions enforced before retrieval Writes validated against current version Policy changes cannot be self-authorized
