Pattern 01 · Prompt chaining

Read slide 4 text
Pattern 01 · Prompt chaining Decompose a known sequence into checked stages. AI AGENT DESIGN PATTERNS 04 Extract Validate Draft Review Publish When to use When outputs depend on a fixed sequence, such as document processing or complaint summarization. Main trade-off More sequential latency; intermediate errors can propagate. Control / failure protection Typed stage contracts; validation gates; stop on failed checks. Evaluate Stage pass rate, end-to-end quality, latency, cost/task.

Context engineering and memory patterns

Read slide 19 text
Context engineering and memory patterns Context is a curated working set, not a full transcript dump. AI AGENT DESIGN PATTERNS 19 • Assemble from instructions, current task, verified retrieval and tool results. • Apply context budgets: relevance, recency, source trust and token ceilings. • Compact into structured state: facts, decisions, pending steps, citations. • Partition memory: ephemeral scratchpad vs approved long-lived facts. • Treat retrieved content as untrusted data, never as new authority.

SLIDE 20 / 30

Tool integration: read vs write vs privileged

Read slide 20 text
Tool integration: read vs write vs privileged Tools expand capability; the gateway enforces actual authority. AI AGENT DESIGN PATTERNS 20 READ Search, retrieval and analytics. Apply data scope, rate limits, query limits and output filtering. WRITE CRM updates, emails, tickets and database mutations. Require validation, idempotency and audit. PRIVILEGED Payments, deployments, deletions and policy changes. Use stronger authorization and human approval. Never rely on a model prompt as the only authorization control.

SLIDE 22 / 30

Evaluate trajectories—not only final responses

Read slide 22 text
Evaluate trajectories—not only final responses Different patterns require different tests and observability. AI AGENT DESIGN PATTERNS 22 Outcome checks Task success, correctness, policy compliance, user utility. Trace checks Plan quality, tool choice/arguments, handoffs, retries and stop behavior. Operational checks Latency p95, token spend, completion rate, escalation time. Adversarial checks Prompt injection, exfiltration, permission bypass and malicious tool results. Release gate = risk-based thresholds + adversarial suites + human review of sampled failures.

Measure whether complexity is earning its place.

Read slide 28 text
30 / 60 / 90-day adoption plan Measure whether complexity is earning its place. AI AGENT DESIGN PATTERNS 28 Days 1–30: baseline Choose 2 workflows; build single-agent baseline; define data, metrics and risk tiers; instrument traces. Days 31–60: compose Add routing or parallelism only where justified; tool gateway; evaluation suites; human queue. Days 61–90: harden Chaos/adversarial tests, budget controls, durable state, runbooks and progressive deployment. Decision: promote pattern only when measured quality / throughput gains exceed added risk and cost.

SLIDE 29 / 30

Best-practice checklist and takeaways

Read slide 29 text
Best-practice checklist and takeaways Production agent design is constrained automation with measured outcomes. AI AGENT DESIGN PATTERNS 29 • Prefer deterministic workflow edges wherever the task structure is known. • Use explicit contracts for state, tool invocations, handoffs and approvals. • Keep model-generated proposals separate from authorization and execution. • Evaluate outputs, tool trajectories, policy adherence, latency and spend. • Record provenance, enforce stop budgets, recover safely and scale autonomy gradually.
