Primary risks: inaccurate or unsafe content, leakage, weak citations. Agentic application Plans steps → calls tools → observes results → changes course → may take actions. Additional risks: unauthorized actions, cascading errors, runaway cost, tool misuse. NEW CONTROL REQUIREMENT: validate both decisions and actions

Tool gateway: the critical enforcement boundary

Read slide 6 text
A G E N T I C A I A S S U R A N C E Tool gateway: the critical enforcement boundary AGENTIC AI • TRUST & CONTROL 06 Agent proposal Tool: issue_refund Amount: $2,450 Customer: C-1028 Reason: duplicate billing The agent proposes an action; it does not grant itself permission. Policy decision Is this user authorized? Is amount within limit? Is this tool allowed? Does it require approval? Are arguments valid? Is the call idempotent? Execution result ALLOW → execute + receipt APPROVAL → pause safely DENY → explain + log RETRY → bounded + safe Record policy version, tool inputs and outcome. The tool gateway is enforced in code—not by asking the model to obey.
