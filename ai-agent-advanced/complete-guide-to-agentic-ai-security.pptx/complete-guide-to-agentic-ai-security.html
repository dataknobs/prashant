Executive takeaways

Executive takeaways Secure actions, not just model text. AGENTIC AI SECURITY • ARCHITECTURE & BEST PRACTICES 02 Agentic AI changes the risk boundary Agents plan, invoke tools, access data, and change systems. Risk includes side effects across a sequence of steps. The model is not the authorization layer A deterministic policy decision and tool gateway must approve every consequential operation. Build security into the harness Identity, budgets, human approvals, tracing, evaluation, rollback and recovery belong in infrastructure.

Prompt injection is a trust-boundary failure

Read slide 9 text
Prompt injection is a trust-boundary failure An attacker tries to promote lower-trust content into authority. AGENTIC AI SECURITY • ARCHITECTURE & BEST PRACTICES 09 Direct injection Adversarial user instruction conflicts with system policy or task constraints. Indirect injection Web pages, emails, documents, tickets and tool responses embed malicious directions. Common objective Override goals, reveal secrets, call privileged tools, alter downstream output or persist attacker state. Defenses in depth Separate data from instructions, delimit content, restrict tool capabilities, monitor intent and outputs.
