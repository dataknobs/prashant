What Is an AI Agent?

A practical definition of AI agents, how they differ from prompts and copilots, and the capabilities that make systems agentic.

Key ideas
  • From prompt to agent
  • Core capabilities
  • A practical mental model
  • When not to use an agent

From prompt to agent

An AI agent is a goal-directed software system that can observe context, reason about what to do next, call tools, keep state, and act toward an outcome. The key step beyond a chatbot is not better prose; it is controlled action.

Core capabilities

Useful agentic systems combine a model with tools, state or memory, planning, execution logic, feedback, and explicit boundaries. Removing any of these may still leave a useful assistant, but with less agency.

A practical mental model

Think in a loop: observe → decide → act → verify → continue or stop. Enterprise design adds policy checks, permissions, logs, retries, and human approval around that loop.

When not to use an agent

If a deterministic workflow, SQL query, rule engine, or standard automation solves the problem reliably, use that simpler mechanism. Agency is justified when the task requires interpretation, adaptation, tool choice, or non-trivial sequencing.
