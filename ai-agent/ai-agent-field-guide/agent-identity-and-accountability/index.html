Agent Identity and Accountability

Why every production agent needs an identity, owner, purpose, permission boundary, and traceable action history.

Key ideas
  • Agents are non-human actors
  • Accountability model
  • Trace actions to origin
  • No shared superuser identity

Agents are non-human actors

Treat production agents as identifiable principals, not anonymous code. They need a stable identity and lifecycle.

Accountability model

Record business owner, technical owner, intended purpose, approved tools, data classifications, autonomy level, and escalation path.

Trace actions to origin

A log should answer who initiated the task, which agent acted, which tool was used, under what policy, and what changed.

No shared superuser identity

Shared high-privilege credentials destroy attribution and make containment harder. Prefer narrowly scoped identities and short-lived authorization.
