Levels of AI Agent Autonomy

A five-level model for deciding how much authority an AI agent should have and how much human oversight is required.

Key ideas
  • Level 1 — Tool
  • Level 2 — Assistant
  • Level 3 — Actor
  • Level 4 — Specialist collaborator

Level 1 — Tool

Human-led, AI-assisted. The system responds on demand but does not independently run the workflow.

Level 2 — Assistant

The agent can execute predefined multi-step work, with approvals at important checkpoints.

Level 3 — Actor

The agent can plan and execute within a defined domain, with guardrails and escalation for edge cases.

Level 4 — Specialist collaborator

The agent operates with high autonomy inside a bounded domain. Humans set policy, review outcomes, and handle exceptional cases.

Level 5 — Cross-domain autonomy

A theoretical frontier where the system can operate broadly with minimal supervision. For enterprise use, this level requires exceptional governance and is rarely an appropriate near-term target.

Design implication

Choose autonomy as a risk decision, not a feature checkbox. Higher autonomy should require stronger controls, narrower permissions, better evaluation, and clearer accountability.
