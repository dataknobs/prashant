Multi-Agent Governance

A governance model for roles, delegation, identity, trust boundaries, shared memory, conflict resolution, and auditability.

Key ideas
  • Separate roles
  • Bound delegation
  • Preserve identity
  • Govern trust boundaries

Separate roles

Planner, executor, reviewer, and monitor roles should remain distinct where separation of duties matters.

Bound delegation

Set maximum delegation depth, detect circular delegation, and track the delegation chain as a graph.

Preserve identity

Every delegated action should remain traceable to the initiating user/system and each intermediate agent. Permissions must never expand through transit.

Govern trust boundaries

Internal and external agents should cross an explicit gateway with authentication, validation, policy enforcement, and logging.

Audit the workflow as a whole

Incident review needs the complete graph: messages, tool calls, memory access, approvals, conflicts, and contributing agents—not isolated logs.
