2.1.1

Encoder vs Decoder

The original Transformer (Vaswani et al. 2017) combined two distinct sub-networks: an Encoder that reads the input, and a Decoder that generates the output. Modern LLMs use one or both halves depending on their task.

Encoder–Decoder (Seq2Seq)

ORIGINAL TRANSFORMER
Models using full Encoder–Decoder

T5, BART, MarianMT, mT5. The encoder processes the full input bidirectionally; the decoder generates outputs autoregressively with causal masking. Cross-attention lets the decoder query the encoder's representations at every step.

Encoder-Only Architecture

BERT-STYLE
Models: BERT, RoBERTa, ALBERT, DeBERTa

Encoder-only models see the full sequence bidirectionally :: every token attends to every other token. Excellent for understanding tasks: classification, NER, question answering. Cannot generate text autoregressively.

Decoder-Only Architecture

GPT-STYLE
Models: GPT-4, Claude, Llama, Gemini, Mistral

Decoder-only models use causal masking :: at position i, attention is allowed only to positions ≤ i. This enables autoregressive generation. The same architecture is used for both training (all positions in parallel with masking) and inference (one token at a time).

2.1.2

Self-Attention

Self-attention allows every token in a sequence to directly query every other token :: computing pairwise relevance scores in a single matrix operation. It is the engine of the Transformer.

QThe Q, K, V Mechanism

Each input token embedding is projected into three vectors via learned weight matrices:

  • Q (Query) :: "What am I looking for?" Represents this token's information need.
  • K (Key) :: "What do I contain?" Acts as an index label for retrieval.
  • V (Value) :: "What I actually contribute." The content aggregated into the output.

2.1.3

Multi-Head Attention

A single attention head can only capture one type of relationship per token pair. Multi-head attention runs h attention heads in parallel :: each learning to attend to different aspects of the input.

Each head uses its own Q, K, V projection matrices (smaller dimension d_k = d_model / h). The outputs are concatenated and projected back to d_model.

Multi-Head Attention

h=8 HEADS
Why Multiple Heads?

Different heads specialise in different linguistic relationships. Head 1 might track syntactic dependencies (subject–verb agreement). Head 2 might track coreference (which pronoun refers to which noun). Head 3 might track positional proximity. Single-head attention can only express one combination of these signals per token pair; multiple heads express all simultaneously.

2.1.4

Positional Encoding

Self-attention is permutation-invariant :: it produces the same output regardless of token order. Positional encoding injects sequence position information so the model can distinguish "the cat sat" from "sat cat the".

PSinusoidal Positional Encoding

The original Transformer uses fixed sinusoidal functions of different frequencies. Each position pos and dimension i gets a unique encoding value, added to the token embedding before the first layer.

Even dimensions (2i)

Sine function :: produces smooth oscillations. Frequency decreases with depth (lower dimensions oscillate faster).

PE(pos, 2i) = sin(pos / 10000^(2i/d_model))

Odd dimensions (2i+1)

Cosine function :: shifted by π/2 from the sine. Together sine+cosine provide a complete phase representation at each frequency.

PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

Sinusoidal PE heatmap :: rows=positions (0–63), columns=dimensions (0–63), colour=value

Each row is added to the corresponding token's embedding. High-freq dims encode fine position differences; low-freq dims encode coarse position.

Sinusoidal vs Learned vs RoPE

Modern LLMs have moved beyond fixed sinusoidal PE. Learned positional embeddings (GPT-2, BERT) train a lookup table per position :: simpler but can't extrapolate beyond training length. Rotary Positional Encoding (RoPE) (Llama, GPT-NeoX) encodes relative positions by rotating Q and K vectors :: enabling better length extrapolation and is now the dominant approach.

2.1.5

Feed-Forward Layers

After attention aggregates information across positions, a position-wise Feed-Forward Network (FFN) applies a non-linear transformation independently to each token. This is where the model "thinks" about the aggregated context.

The FFN is a two-layer MLP: expand to 4× the model dimension, apply a non-linearity (ReLU or GELU), then project back down. Critically, it is applied identically and independently at each token position :: no cross-position interaction occurs here.

Feed-Forward Network (per token)

POSITION-WISE
The Role of the FFN

Interpretability research (e.g. Geva et al. 2021) suggests FFN layers act as key-value memories :: the first layer detects patterns (keys) and the second outputs associated information (values). Up to 70% of an LLM's factual knowledge may be stored in its FFN weights, not its attention matrices.

2.1.6

Residual Connections & Layer Normalization

Two training stability techniques that are invisible in diagrams but essential in practice :: without them, deep Transformers (96+ layers in GPT-4) are untrainable.

Residual Connections

Each sub-layer's output is added to its input: output = x + Sublayer(x). The gradient flows directly through the addition :: bypassing the sub-layer entirely if needed. This prevents vanishing gradients in very deep networks.

x_out = LayerNorm(x + Attention(x))
x_out = LayerNorm(x + FFN(x))

Layer Normalization

Normalises activations across the feature dimension (not batch dimension) to zero mean and unit variance. Stabilises training and reduces sensitivity to learning rate. Applied before (Pre-LN) or after (Post-LN) each sub-layer.

LayerNorm(x) = γ · (x − μ)/σ + β
γ, β: learned scale and shift
Pre-LN (GPT-2+) is more stable

1Scaled Dot-Product Attention

attention.py
PYTORCH 
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

def scaled_dot_product_attention(
    q: torch.Tensor,   # [batch, heads, seq, d_k]
    k: torch.Tensor,   # [batch, heads, seq, d_k]
    v: torch.Tensor,   # [batch, heads, seq, d_v]
    mask: torch.Tensor = None,  # [batch, 1, seq, seq] boolean
    dropout: float = 0.0,
) -> tuple[torch.Tensor, torch.Tensor]:
    """
    Compute Attention(Q,K,V) = softmax(QKᵀ / √dₖ) · V
    Returns: (output [batch,heads,seq,d_v], weights [batch,heads,seq,seq])
    """
    d_k = q.size(-1)

    # Step 1: Compute raw attention scores QKᵀ
    scores = torch.matmul(q, k.transpose(-2, -1))  # [B, H, Seq, Seq]

    # Step 2: Scale by 1/√dₖ to stabilize gradients
    scores = scores / math.sqrt(d_k)

    # Step 3: Apply mask (causal or padding)
    if mask is not None:
        # -1e9 → effectively -∞ before softmax → 0 after
        scores = scores.masked_fill(mask == 0, -1e9)

    # Step 4: Softmax over the key dimension
    weights = F.softmax(scores, dim=-1)  # [B, H, Seq, Seq]

    # Step 5: Optional dropout on attention weights
    if dropout > 0.0:
        weights = F.dropout(weights, p=dropout, training=True)

    # Step 6: Weighted sum of values
    output = torch.matmul(weights, v)  # [B, H, Seq, d_v]

    return output, weights


# ── Quick test ──
B, H, S, D = 2, 4, 8, 64   # batch, heads, seq_len, head_dim
q = torch.randn(B, H, S, D)
k = torch.randn(B, H, S, D)
v = torch.randn(B, H, S, D)

# Causal mask :: lower triangular (decoder-style)
causal_mask = torch.tril(torch.ones(S, S)).bool().unsqueeze(0).unsqueeze(0)

out, attn_weights = scaled_dot_product_attention(q, k, v, mask=causal_mask)
print(f"Output shape:  {out.shape}")          # → torch.Size([2, 4, 8, 64])
print(f"Weights shape: {attn_weights.shape}")  # → torch.Size([2, 4, 8, 8])
print(f"Weights sum:   {attn_weights[0,0,0].sum():.4f}")  # → 1.0000 (softmax)

2Multi-Head Attention Module

multi_head_attention.py
PYTORCH 
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model: int, n_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % n_heads == 0, "d_model must be divisible by n_heads"

        self.d_model  = d_model
        self.n_heads  = n_heads
        self.d_k      = d_model // n_heads  # head dimension
        self.dropout  = dropout

        # Projection matrices (W_q, W_k, W_v fused for efficiency)
        self.W_qkv = nn.Linear(d_model, 3 * d_model, bias=False)
        self.W_o   = nn.Linear(d_model, d_model, bias=False)

        # Initialise with small weights (stabilises training)
        nn.init.xavier_uniform_(self.W_qkv.weight)
        nn.init.xavier_uniform_(self.W_o.weight)

    def forward(
        self,
        x: torch.Tensor,              # [batch, seq, d_model]
        mask: torch.Tensor = None,   # [batch, 1, seq, seq]
        return_weights: bool = False,
    ) -> torch.Tensor:
        B, S, _ = x.shape

        # 1. Project input to Q, K, V (all at once, then split)
        qkv = self.W_qkv(x)                    # [B, S, 3·d_model]
        q, k, v = qkv.split(self.d_model, dim=-1)  # each [B, S, d_model]

        # 2. Reshape to [B, H, S, d_k] for parallel head computation
        def reshape_heads(t):
            return t.view(B, S, self.n_heads, self.d_k).transpose(1, 2)

        q, k, v = reshape_heads(q), reshape_heads(k), reshape_heads(v)

        # 3. Scaled dot-product attention (all heads in parallel)
        attn_out, weights = scaled_dot_product_attention(
            q, k, v, mask=mask, dropout=self.dropout if self.training else 0.0
        )   # attn_out: [B, H, S, d_k]

        # 4. Concatenate heads and project
        attn_out = attn_out.transpose(1, 2).contiguous().view(B, S, self.d_model)
        output   = self.W_o(attn_out)  # [B, S, d_model]

        return (output, weights) if return_weights else output

    def extra_repr(self) -> str:
        return f"d_model={self.d_model}, n_heads={self.n_heads}, d_k={self.d_k}"

class TransformerBlock(nn.Module):
    """One decoder-style Transformer block (Pre-LayerNorm)."""

    def __init__(self, d_model: int, n_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.norm1   = nn.LayerNorm(d_model)
        self.attn    = MultiHeadAttention(d_model, n_heads, dropout)
        self.norm2   = nn.LayerNorm(d_model)
        self.ff      = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout),
        )

    def forward(self, x: torch.Tensor, mask: torch.Tensor = None) -> torch.Tensor:
        # Pre-LN: normalise BEFORE each sub-layer (more stable than post-LN)
        x = x + self.attn(self.norm1(x), mask=mask)  # residual + attention
        x = x + self.ff(self.norm2(x))               # residual + FFN
        return x


class MiniGPT(nn.Module):
    """Tiny GPT-style decoder-only Transformer."""

    def __init__(
        self,
        vocab_size: int = 50257,
        d_model: int    = 256,
        n_heads: int    = 8,
        n_layers: int   = 6,
        max_seq: int    = 512,
        dropout: float  = 0.1,
    ):
        super().__init__()
        self.token_emb = nn.Embedding(vocab_size, d_model)
        self.pos_emb   = nn.Embedding(max_seq, d_model)   # learned PE
        self.drop      = nn.Dropout(dropout)
        self.blocks    = nn.ModuleList([
            TransformerBlock(d_model, n_heads, d_ff=d_model * 4, dropout=dropout)
            for _ in range(n_layers)
        ])
        self.norm      = nn.LayerNorm(d_model)
        self.lm_head  = nn.Linear(d_model, vocab_size, bias=False)

        # Weight tying: share token embedding and lm_head weights (saves params)
        self.lm_head.weight = self.token_emb.weight

        # Count parameters
        total = sum(p.numel() for p in self.parameters())
        print(f"MiniGPT initialised: {total/1e6:.1f}M parameters")

    def forward(self, idx: torch.Tensor) -> torch.Tensor:
        B, S = idx.shape
        pos  = torch.arange(0, S, device=idx.device).unsqueeze(0)

        # Token + positional embeddings
        x = self.drop(self.token_emb(idx) + self.pos_emb(pos))

        # Causal mask: token i can only see tokens 0…i
        mask = torch.tril(torch.ones(S, S, device=idx.device)).bool()

        for block in self.blocks:
            x = block(x, mask=mask.unsqueeze(0).unsqueeze(0))

        x      = self.norm(x)
        logits = self.lm_head(x)  # [B, S, vocab_size]
        return logits


# ── Instantiate and run a forward pass ──
model = MiniGPT(d_model=256, n_heads=8, n_layers=6)
# → "MiniGPT initialised: 21.3M parameters"

dummy_input = torch.randint(0, 50257, (2, 64))  # batch=2, seq_len=64
logits      = model(dummy_input)

print(f"Input shape:   {dummy_input.shape}")  # [2, 64]
print(f"Logits shape:  {logits.shape}")       # [2, 64, 50257]
print(f"Next token probs (argmax): {logits[:, -1, :].argmax(dim=-1)}")
